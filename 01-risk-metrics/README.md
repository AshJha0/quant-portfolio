# Project 1 — Risk Metrics on Real Data

Compute and interpret core risk metrics for a single asset: volatility (three estimators), Value at Risk (three methods), Expected Shortfall, maximum drawdown, Sharpe/Sortino ratios, and distribution diagnostics.

The point of this project is not the arithmetic — it is showing that different methods give different answers, understanding *why*, and knowing which assumptions each one leans on.

## How to run

```
pip install -r requirements.txt
python analysis.py                 # runs on the bundled sample data
```

To use real market data (recommended before showing this to anyone):

```
pip install yfinance
python download_data.py SPY 2016-01-01
python analysis.py data/SPY.csv
```

Outputs go to `output/report.txt` and `output/figures/`.

## Data

The repository ships with `data/sample_prices.csv`, a **synthetic** series generated by `generate_sample_data.py` (a two-regime model with Student-t shocks). It exists only so the code runs offline. It deliberately reproduces the stylised facts of real returns — fat tails, volatility clustering, drawdowns — so the analysis is meaningful, but any conclusions you present should be drawn from real data via `download_data.py`.

When using real data, note that adjusted close prices are used, so dividends and splits are already folded into the return series.

## Methodology and assumptions

**Returns.** Simple daily returns (`P_t / P_{t-1} - 1`). Log returns are also provided in the library; for daily horizons the difference is negligible, but the choice matters when compounding (log returns add over time, simple returns add across assets).

**Volatility.** Three estimators, because "the" volatility does not exist:
- *Full-sample* standard deviation, annualised with √252. This assumes returns are i.i.d. — variance scales linearly with horizon. Real returns cluster, so this is an approximation.
- *21-day rolling* — reflects the current month's regime.
- *EWMA (λ = 0.94)* — RiskMetrics convention; reacts faster to regime shifts because recent observations dominate.

When the EWMA figure diverges sharply from the full-sample figure, the unconditional number is describing a market that no longer exists.

**Value at Risk.** Reported as a positive loss at 95% and 99% confidence, 1-day horizon:
- *Historical* — empirical quantile. No distributional assumption, but assumes the sample window is representative of the future.
- *Gaussian (parametric)* — assumes normality. Included largely to demonstrate its failure: daily returns have excess kurtosis, so Gaussian VaR understates 99% risk.
- *Cornish-Fisher* — adjusts the Gaussian quantile for the sample's skewness and kurtosis. A pragmatic middle ground, though unstable when higher moments are estimated from small samples.

**Expected Shortfall** — the average loss *given* the loss exceeds VaR. It answers "how bad is the tail", where VaR only answers "where does the tail start", and unlike VaR it is sub-additive.

**Sharpe / Sortino.** Constant 3% annual risk-free rate assumed; √252 annualisation again requires i.i.d. returns (positive autocorrelation inflates the ratio). Sortino penalises only downside deviation.

**Normality test.** Jarque-Bera. For daily equity returns it essentially always rejects normality — the report makes this explicit because it is the justification for not trusting Gaussian VaR at high confidence.

## What the results mean

On the bundled sample (and on most real equity data) you should observe:

1. **Historical 99% VaR > Gaussian 99% VaR.** Fat tails: the normal distribution assigns too little probability to extreme days.
2. **ES noticeably above VaR** at the same confidence — the tail is not a cliff edge but a slope; VaR alone hides its depth.
3. **JB test rejects normality decisively**, with excess kurtosis well above zero.
4. **Volatility is time-varying** — the rolling/EWMA plot shows clear clustering, which is why a single unconditional number is a blunt instrument.

## Limitations and what I would improve

- Historical VaR is fully backward-looking; a filtered approach (GARCH or EWMA-scaled historical simulation) would adapt to current volatility.
- One asset only. Portfolio VaR introduces correlation, which is the actually hard part.
- No backtesting of the VaR model itself (Kupiec / Christoffersen exception tests) — that would be the natural next step to check whether "99%" VaR is really exceeded on ~1% of days.
- Constant risk-free rate is a simplification; a T-bill series would be more accurate for the Sharpe ratio.
