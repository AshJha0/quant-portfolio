# Methodology

Rust FX VaR/ES engine: the port of the Python package
`python/fx/03-var-es-engine` (`fx_var`), alongside the C++ engine
`cpp/fx-var-engine` (`fxvar`). Books hold cash, spot and forwards. FX
options (Garman-Kohlhagen) are revalued in the Python package only. This
file states the conventions, the model choices and the assumptions. The
Python `docs/METHODOLOGY.md` carries the full derivations.

Evidence classes: *test* (a named test in this crate), *golden* (a value
generated by the Python reference and checked here), *derivation*.

## 0. Conventions (shared by every VaR engine in the repository)

| Item | Convention |
|---|---|
| `alpha` | **Tail probability**: `0.01` is 99 % VaR. Every public function rejects `alpha` outside `(0, 0.5)` with "alpha is the tail probability (e.g. 0.01 for 99 %)". Until 0.2.0 this crate took a confidence level; `0.99` is now an error, never reinterpreted. |
| Empirical VaR | Losses sorted descending, `k = n alpha`, `m = ceil(k - 1e-9)` clamped to `[1, n]`, `VaR = L(m)`. |
| Empirical ES | `[sum_{i<m} L(i) + (k - (m-1)) L(m)] / k`. Weighted: `m` = first `j` with `W_j >= alpha - 1e-12`, `ES = [sum_{i<m} w_i L(i) + (alpha - W_{m-1}) L(m)] / alpha`. |
| Closed forms | `z = Phi^{-1}(1 - alpha)`; normal `VaR = -mu + sigma z`, `ES = -mu + sigma phi(z)/alpha`; standardised t with `q = t^{-1}(1 - alpha)`. |
| Kupiec, Basel | Struct inputs `{ n_obs, n_exceptions, alpha }`. Basel zone by `Binomial(n, alpha)` CDF for any window. |
| EWMA vol | Zero mean; seed = mean `r^2` over the first `min(30, n)` rows. |
| Cholesky | Relative symmetry `1e-10 max|A|`; jitter `1e-12 .. 1e-6 x mean(diag)`, reported; optional Clip or Higham. |
| Empty book | Error "book has no positions". |

Worked example (*test* `order_statistic_and_fractional_es_by_hand`): losses
`1..=10`, `alpha = 0.25`: `k = 2.5`, `m = 3`, `VaR = 8`, `ES = 9.2`.

The old confidence rule (cumulative tail weight reaching `1 - alpha`) and
the new rule pick the same order statistic on equal weights; only the
argument changed. The FX golden values for cases A and B are unchanged in
the first 15 digits (*golden* `A_PLAIN_VAR_99`, `B_NORMAL_VAR_99_1D`; the
key names keep the old labels).

## 1. Factor model and book

- Pairs are BASE/QUOTE (EURUSD = USD per EUR). Each currency has one USD
  factor `FX:CCY`, the daily log return of CCYUSD. Crosses are triangulated
  through their USD legs (*test* `book::tests::triangulation_identity_eurjpy`).
- `IR:CCY` is an absolute shock to the continuously compounded ACT/365 zero
  rate, flat per currency.
- Forwards are spot plus two deposit legs:
  `V_usd = N e^{-r_f T} S_f - N K e^{-r_d T} S_d` (CIP).
- P&L in the base currency: `V1_usd/S1_base - V0_usd/S0_base`.
- `CompiledBook` flattens positions into legs at construction; a scenario
  revalues each leg as `v0 exp(dfx - T dr)`.

## 2. VaR methods

- **Historical simulation**: plain, BRW age weights, and filtered HS per
  factor (EWMA sigma with the S8 seed, rescaled to the one-step-ahead vol),
  all with full revaluation of the book and the S2 estimator.
- **Parametric**: finite-difference exposures plus normal or standardised t
  on the same sigma.
- **Cornish-Fisher (S6)**: `cornish_fisher_valid(skew, kurt, alpha)` checks
  `g'(z) > 0` on `[-z_a, z_a]`, `z_a = Phi^{-1}(1 - alpha)`, in closed form
  (`g'` is a quadratic). Non-finite moments are an error. The old fixed
  interval `|z| <= 4` rejected `(0.122, -0.427)`, whose minimum derivative
  is at the endpoint `z = -4`; at `alpha = 0.01` that pair is valid
  (*golden* `CONV_CF_VALID_S0122_KM0427`). The old predicate stays one
  release, deprecated.
- **Monte Carlo (S10)**: normal, covariance-matched t, and the jump
  overlay. The per-day jump probability `p` gives the intensity
  `lam = -ln(1 - p)`; the count over the horizon `h` is
  `N ~ Poisson(lam h)` and each listed factor moves by the sum of `N` iid
  jump sizes, `N mu_J + sigma_J sqrt(N) Z`. The jump is uncompensated: it
  adds drift `lam h mu_J` and variance on top of the covariance. The old
  overlay drew one Bernoulli(p) jump whatever the horizon, so a 10-day VaR
  carried 1-day jump risk (*test* `jump_count_scales_with_horizon`).
  Simulation happens once per call; VaR, ES and both SEs come from the
  same scenarios.
- **Standard errors**: the bootstrap SE is primary (resample the scenario
  P&L, recompute the S2 VaR, sample std, `n_boot >= 2`, default 200). The
  KDE SE (Silverman bandwidth at the reported quantile) is a diagnostic; a
  fixed bandwidth tends to understate the SE deep in the tail.

## 3. Backtests

- Kupiec (S3), Christoffersen independence, conditional coverage.
- Basel (S4): `F(x)` by pmf recursion, green `< 0.95`, yellow `< 0.9999`,
  red otherwise; yellow plus factor from the 1996 table at the equivalent
  250-day count. The old code took the add-on from the raw count: 15
  exceptions in 1000 days (`F = 0.952`) got 0.85; now 0.40 (*golden*
  `CONV_BASEL_K_N1000_X15_A010`).
- Acerbi-Szekely Z2 (S5), paper sign, statistic only.

## 4. Cholesky and PSD repair

`psd::cholesky_repair` (see the equity crate's METHODOLOGY section 3 for
the full rule). Two currencies pegged to the same anchor give a singular
covariance, which takes a small jitter, reported in
`MonteCarloResult::jitter` and `cholesky_warning`. A materially indefinite
matrix is an error naming the most negative eigenvalue; Clip and Higham
repairs exist but the MC path never applies them on its own.

## 5. Assumptions register

| # | Assumption | What breaks if violated |
| --- | --- | --- |
| A1 | Cross risk is captured by the two USD legs. | Offshore/onshore splits (CNH vs CNY) need their own factor. |
| A2 | `FX:*` are log returns; scenarios exponentiate. | Simple returns mis-state large shocks. |
| A3 | Flat zero curve per currency. | Curve-shape and basis risk are invisible. |
| A4 | CIP holds in revaluation. | Stressed cross-currency basis needs a basis factor. |
| A5 | Square-root-of-time for multi-day horizons. | Understates 10-day risk for carry books. |
| A6 | Covariance is stationary within the window. | Regime breaks; EWMA recovers with a lag. |
| A7 | i.i.d. scenarios within the HS window (plain). | Clustering fails Christoffersen; use FHS. |
| A8 | Pegs: the history contains no break. | HS and parametric VaR are near zero on a peg. The engine flags pegs and prices breaks with the jump overlay and peg-break scenarios. |
| A9 | The crate-owned RNG drives every draw. | Changing `rng.rs` or `qp_core::rng` changes every seeded number. Results repeat on the same build and platform; no cross-platform claim. |
| A10 | Linear instruments only. | Options need the Python GK layer. |
| A11 | Jump overlay is uncompensated. | It shifts the mean as well as the tail; compare against a compensated model before attributing the VaR change to tail risk alone. |

## 6. Design choices

- **`Result` everywhere, no panics on user input.** The old `assert!`s in
  `inv_norm_cdf`, the incomplete gamma and beta, `Rng::gamma` and the
  Cornish-Fisher grid argument were reachable from user input; they are
  gone. `stress.rs` builds its library constants without `unwrap`.
  The fuzz walk (`tests/fuzz_public_api.rs`) covers every public function.
- **Refuse, never impute.** An empty book is an error, not a zero VaR.
- **Special functions from `qp_core::stats`** (one copy shared with the
  equity engine since milestone v2.1; `stats.rs` here is a wrapper), with
  the series and continued-fraction stopping threshold at one machine
  epsilon. The shared normal CDF uses the `erfc` form; the old in-crate
  `(1 - P(1/2, x^2/2))/2` cancelled in the lower tail: `norm_cdf(-8)` was
  6.106e-16 (1.8 % low) and is now 6.220960574271834e-16 (mpmath
  6.220960574271784e-16), and `norm_cdf(-10)` was 0 and is now 7.62e-24.
  At the alphas the engine uses (0.001 to 0.05) values moved by at most
  4.8e-14 relative (CHANGELOG, milestone v2.1).
- **RNG**: xoshiro256++ with the shared inverse normal CDF from
  `qp_core::stats`. The FX engine has not moved to the per-path Philox
  streams that the equity engine uses. The stream
  differs from the C++ engine's `mt19937_64` and from NumPy's, so
  cross-engine MC agreement is statistical.
