# Methodology

This crate is the linear-book port of the Python library `eq_var`
(`python/equity/03-var-es-engine`). It revalues a book linearly: dollar
exposures times factor returns. The Python library also does full
revaluation of options. Both follow the repository-wide conventions below,
and the shared goldens (`conv_*` keys) check them in Python, C++ and Rust.

Each section gives the idea in words, the formula, and where it is tested.
Evidence classes: *test* (a named test in this crate), *golden* (a value
generated by the Python reference and checked here), *derivation* (follows
from the formula).

## 0. Conventions (shared by every VaR engine in the repository)

| Item | Convention |
|---|---|
| `alpha` | Tail probability. `alpha = 0.01` is 99 % VaR. Every public function rejects `alpha` outside `(0, 0.5)` with "alpha is the tail probability (e.g. 0.01 for 99 %)". |
| Sign | P&L in currency, loss negative. VaR and ES are reported positive for a loss. |
| Empirical VaR | Losses `L = -pnl` sorted descending. `k = n alpha`, `m = ceil(k - 1e-9)` clamped to `[1, n]`. `VaR = L(m)`. No interpolation. |
| Empirical ES | `ES = [sum_{i<m} L(i) + (k - (m-1)) L(m)] / k` (Acerbi-Tasche, exact fractional atom). |
| Weighted (BRW) | Weights normalised, sorted with the losses (stable). `m` = first `j` with `W_j >= alpha - 1e-12`. `ES = [sum_{i<m} w_i L(i) + (alpha - W_{m-1}) L(m)] / alpha`. |
| Kupiec | `kupiec_pof(&KupiecInput { n_obs, n_exceptions, alpha })`. |
| Basel | Zone from `F(x) = P(X <= x)`, `X ~ Binomial(n_obs, alpha)`, any window. |
| EWMA | Zero-mean RiskMetrics. Seed = mean of `r^2` over the first `min(30, n)` observations. |
| Cholesky | Symmetry `|A - A'| <= 1e-10 max|A|`. Jitter `1e-12 .. 1e-6 x mean(diag)`, reported. Optional Clip or Higham repair. |
| Empty book | Error "book has no positions". |
| Bad input | NaN, `+/-inf`, empty, too short or negative where invalid: `Err`, never a number. |

Worked example (*test* `tail::empirical_var_es` doctest): losses `1..=10`,
`alpha = 0.25`. `k = 2.5`, `m = 3`, `VaR = L(3) = 8`,
`ES = (10 + 9 + 0.5 x 8) / 2.5 = 9.2`.

The `1e-9` guard keeps a `k` that is an integer up to rounding on the integer
rank: `250 x 0.02 = 5.000000000000001` gives `m = 5`, not 6 (*test*
`order_statistic_var_and_fractional_es_by_hand`).

## 1. Historical simulation (`src/historical.rs`, `src/tail.rs`)

**Plain HS.** VaR is the S2 order statistic of the P&L sample. The
implementation finds `L(m)` with `select_nth_unstable_by` (`total_cmp`), which
is `O(n)`, then sums the `m - 1` larger losses after sorting only those, so
the rounding is fixed. Until 0.2.0 this crate used type-7 interpolation. On
the 100-point case A sample that moved 99 % VaR from 122.41 to 141.76
(*golden* `A_HIST_VAR_1PCT`): at `n alpha = 1` the order statistic is the
worst loss, while type-7 interpolated between the worst and second worst.
`linear_quantile` stays one release, deprecated.

**BRW age weights.** Observation `i` (0 = oldest) gets
`w_i = (1-lam) lam^{n-1-i} / (1-lam^n)`. VaR uses the weighted S2 rule.

**Filtered HS, per factor (S9).** For each factor `j`: EWMA vol
`sigma_{t,j}` (lam 0.94, seed window 30), `z_{t,j} = r_{t,j} / sigma_{t,j}`,
rescaled scenarios `r*_{t,j} = z_{t,j} sigma_{T+1,j}` with the one-step-ahead
vol. The book is revalued linearly, `pnl_t = w . r*_t`, and VaR is S2
(`filtered_historical_var_factors`, *test* `per_factor_fhs_matches_hand_recipe`).
The Python library revalues the rescaled scenarios in full; for a linear
book the two agree by construction.

The old `filtered_historical_var(pnl, ...)` filtered the scalar P&L. That
mixes the vol of the factors with the book's changing mix of them. It stays
one release, deprecated, with its old arithmetic (full-sample variance seed,
type-7 quantile) so that its number does not move (*golden*
`A_FHS_VAR_5PCT_LAM094`).

**Square-root-of-time.** `VaR_h = VaR_1 sqrt(h)`. Exact only for i.i.d.
zero-drift returns; it understates multi-day risk under volatility
clustering. `overlapping_horizon_pnl` gives the direct h-day sample, with an
effective size of about `n/h`.

## 2. EWMA volatility and covariance

Volatility (S8): `s2_t = lam s2_{t-1} + (1-lam) r_{t-1}^2`, zero mean.
`s2_0` is the mean of `r^2` over the first `min(30, n)` observations. Days
inside that window are standardised with a seed that saw them; there is no
full-sample seed (*test* `ewma_seed_uses_first_30_observations_only`, *golden*
`CONV_EWMA_SIGMA_LAST`).

Covariance: `Sigma <- lam Sigma + (1-lam) r_t r_t'` over every row, seeded
with the zero-mean second moment `mean(r r')` of the first `min(30, T)` rows
(`EWMA_COV_SEED_WINDOW`, convention S8), so the seed uses no later data. It
matches the Python `ewma_covariance` (*golden* `C_EWMA_COV_*`, *test*
`ewma_covariance_seed_uses_first_window_rows_only`).

## 3. Cholesky and PSD repair (`src/psd.rs`)

`cholesky_repair(A, repair)`:

1. Symmetry check relative to the largest entry: `|a_ij - a_ji| <= 1e-10 max|A|`.
2. Plain Cholesky. On failure add `eps I`, `eps = 1e-12 mean(diag)`, x10 per
   try, last try `1e-6 mean(diag)`. The jitter used is returned in
   `CholeskyFactor::jitter`. A PSD-but-singular matrix (a riskless leg, two
   perfectly correlated factors) is fixed at a small rung (*test*
   `singular_matrix_reports_jitter_within_cap`).
3. Past the cap: `PsdRepair::None` returns an error naming the most negative
   eigenvalue. `Clip` floors eigenvalues at `1e-10 mean(diag)` and restores
   the original diagonal by `D^{1/2}` scaling. `Higham` runs Higham (2002)
   alternating projections with Dykstra's correction on the correlation
   matrix (tolerance `1e-12` relative on successive iterates, at most 1000
   iterations) and rescales by the original vols.

The eigen solver is cyclic Jacobi (*test* `eigen_reconstructs_the_matrix`).
Worked example (*golden* `CONV_HIGHAM_*`, `CONV_CLIP_*`): the matrix with
unit diagonal and off-diagonals `0.9, 0.9, -0.9` has eigenvalue `-0.8`.
Plain Cholesky fails. Higham gives off-diagonals `0.5, 0.5, -0.5`
(to `1.6e-13`); clipping gives `0.49999999996`.

Monte Carlo uses `PsdRepair::None`: a materially indefinite covariance is a
data problem and is reported, not patched.

## 4. Parametric VaR (`src/parametric.rs`)

`sigma_p = sqrt(w' Sigma w)`, `VaR = -(mu h + z sigma_p sqrt(h))` with
`z = Phi^{-1}(alpha)` (normal) or the variance-matched Student-t quantile
`t_nu^{-1}(alpha) sqrt((nu-2)/nu)`, `nu > 2`. Variance matching keeps sigma
fixed so the normal-to-t change is tail shape only.

**Cornish-Fisher (S6).** `g(z) = z + (z^2-1)S/6 + (z^3-3z)K/24 - (2z^3-5z)S^2/36`
with skewness `S` and excess kurtosis `K`. It is a valid quantile map at
tail probability `alpha` iff `g'(z) > 0` on `[-z_a, z_a]`,
`z_a = Phi^{-1}(1 - alpha)`. `g'` is a quadratic, so the minimum on the
interval is at the vertex (if convex and inside) or at an endpoint: the
check is exact (`cornish_fisher_valid(skew, kurt, alpha) -> Result<bool>`).
Non-finite moments are an error, not `false`.

Worked example (*golden* `CONV_CF_VALID_*`): `(S, K) = (0.122, -0.427)`.
`g'` is concave, so its minimum on an interval is at an endpoint. On the old
fixed interval `|z| <= 4` the minimum is at `z = -4` and is negative. At
`alpha = 0.01` (`z_a = 2.33`) and at `alpha = 0.001` (`z_a = 3.09`) it is
positive, so the map is valid. The old fixed-interval predicate
`cornish_fisher_domain_ok` stays one release, deprecated.

## 5. Monte Carlo (`src/monte_carlo.rs`)

Factor returns `r = L z` with `z ~ N(0, I)` (Box-Muller) or the
multivariate t (`r = L z / sqrt(W/nu)`, `W ~ chi^2_nu`, scale matrix
`Sigma (nu-2)/nu` so the simulated covariance is `Sigma`). P&L is `w . r`.

For a linear book with normal factors MC reproduces the parametric number;
it is a check of the closed form, not new information. The C++ and Rust
engines are linear-book ports; option revaluation lives in Python.

`monte_carlo_run` simulates once and returns VaR, ES, the bootstrap SE
(primary) and the KDE SE (diagnostic) from the same scenarios, plus the
Cholesky jitter.

- **Bootstrap SE.** Resample the scenario P&L with replacement `n_boot`
  times (`n_boot >= 2`), recompute the S2 VaR (selection, one buffer, never
  an `n_boot x n` index matrix), take the sample standard deviation.
- **KDE SE.** `sqrt(alpha(1-alpha)/n) / f(q)` with `q` the reported S2
  quantile and `f` a Gaussian KDE with Silverman's bandwidth
  `0.9 min(sd, IQR/1.34) n^{-1/5}`. A fixed bandwidth is tuned to the bulk,
  so deep in the tail it tends to understate the SE.

The old symmetric finite-difference SE (`var_order_statistic_se`) stays one
release, deprecated.

**Determinism.** One seeded `Rng` (xoshiro256++, Box-Muller, Marsaglia-Tsang
gamma) drives every draw. A seed repeats exactly on the same build and
platform (*test* `bitwise_seed_determinism`). Across platforms `ln`, `sin`
and `cos` come from the platform libm, so no cross-platform claim is made.
The stream differs from NumPy's and the C++ engine's, so cross-engine MC
agreement is statistical.

## 6. Expected Shortfall (`src/expected_shortfall.rs`)

Empirical ES is the S2 Acerbi-Tasche estimator; `ES >= VaR` for every
sample because VaR is `L(m)`. Closed forms: normal
`ES = sigma phi(z)/alpha - mean`, `z = Phi^{-1}(alpha)`; variance-matched t
`ES = sigma f_nu(q)(nu+q^2)/((nu-1) alpha) sqrt((nu-2)/nu) - mean`.

## 7. Backtesting (`src/backtest.rs`)

An exception is a day with `pnl < -VaR`. NaN in either series is an error,
since a NaN day compares false and would count as no exception.

- **Kupiec (S3).** `LR = -2 ln[(1-a)^(n-x) a^x] + 2 ln[(1-p)^(n-x) p^x]`,
  `p = x/n`, `0 ln 0 = 0`, chi2(1) p-value. Named fields stop the old silent
  swap of `n_obs` and `n_exceptions` (*golden* `CONV_KUPIEC_LR_*`).
- **Christoffersen** independence and conditional coverage, chi2(1) and
  chi2(2).
- **Basel traffic light (S4).** `F(x)` by the pmf recursion
  `pmf(0) = exp(n log1p(-alpha))`, `pmf(j+1) = pmf(j) (n-j)/(j+1) alpha/(1-alpha)`.
  Green if `F < 0.95`, yellow if `F < 0.9999`, red otherwise. Yellow plus
  factor from the 1996 table at the equivalent 250-day count: the smallest
  `x'` in `5..=9` with `F_250(x') >= F(x) - 1e-12`. Worked example
  (*golden* `CONV_BASEL_*`): 5 exceptions in 500 days is green (`F = 0.616`);
  the old code put any 5 in yellow whatever the window. 15 in 1000 days is
  yellow with `F = 0.952`, plus factor 0.40. An exception count above the
  window is an error (it used to be clamped).
- **Acerbi-Szekely Z2 (S5).** `Z2 = sum_t pnl_t I_t / (T alpha ES_t) + 1`,
  paper sign: negative means ES is understated. This crate returns `Z2`
  only; the simulated p-value is in the Python library.

## 8. Special functions (`src/stats.rs`)

- `Phi^{-1}`: Acklam plus one Halley step.
- Incomplete beta and gamma by continued fractions and series, with the
  stopping threshold one machine epsilon (`2.2e-16`). The old `1e-16` was
  below half an ulp at 1.0, so the test passed only on exact equality.
- Student-t quantile by bisection on the CDF.
- `erfc`, `erf`, `normal_cdf`, `normal_pdf` are total: NaN in, NaN out,
  limits at `+/-inf`. `erfc(NaN)` used to recurse without end and
  `erfc(+inf)` panicked (*test*
  `special_functions_never_panic_or_hang_on_non_finite_input`).

## Assumptions register

Each item says what breaks if it is violated.

1. **Linear P&L** `pnl = w' r`. Options and gamma are not modelled here; use
   the Python full revaluation.
2. **Stationarity over the window.** Plain HS lags regime breaks; FHS and
   BRW respond faster; Christoffersen detects clustering.
3. **Zero-mean daily returns** in EWMA. Second order at a daily horizon;
   `parametric_var_full` takes a mean.
4. **i.i.d. for sqrt-time.** Understates 10-day VaR in clustered regimes.
5. **Student-t `df > 2`.** Otherwise there is no variance to match; error.
6. **Cornish-Fisher inside its validity region at the requested `alpha`.**
   Outside, the engine returns an error.
7. **Covariance PSD up to rounding.** Rounding-level indefiniteness takes a
   reported jitter; material indefiniteness is an error unless a repair is
   requested.
8. **Basel plus factors** are the 1996 250-day table, mapped by equivalent
   count for other windows and alphas. That mapping is a convention of this
   repository, not a regulatory rule.
9. **RNG stream is crate-specific.** Changing `rng.rs` or
   `qp_core::rng` changes every seeded number.
