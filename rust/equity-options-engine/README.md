# Equity Options Pricing Engine (Rust)

Zero-dependency Rust twin of the Python reference package
[`eq_options`](../../python/equity/01-options-pricing/) and the
[C++ engine](../../cpp/equity-options-engine/) — the same models, the same
conventions, cross-validated against golden vectors *generated by the
Python project*. Where Python is the research reference and C++ the
incumbent production shape, this crate is the memory-safe production
implementation: ~12 million analytic prices per second on a single core,
`cargo test` green under `RUSTFLAGS="-D warnings"`, and **zero external
crates** — the deterministic RNG (SplitMix64-seeded xoshiro256++ with
Box-Muller normals) and the erfc-based normal CDF (Cody's rational
approximation) are implemented in-crate against `std` only.

## Models

| Module (`src/`) | Contents |
|---|---|
| `black_scholes.rs` | European call/put with continuous dividend yield `q`; `d1`/`d2`; erfc-based normal CDF (Cody, verified to < 2e-15 rel); documented `T=0` / `sigma=0` limits; `Result<_, PricingError>` errors |
| `greeks.rs`        | Analytic delta, gamma, vega, theta, rho, vanna, volga; generic central finite-difference Greeks over *any* pricer closure |
| `implied_vol.rs`   | Bracketed Newton with bisection fallback; 1e-10 price tolerance; rejects sub-intrinsic quotes as `ArbitrageBound` errors |
| `binomial.rs`      | CRR tree, European + American, dividend yield, O(n)-memory single-vector backward induction |
| `black76.rs`       | Options on forwards/futures: price + Greeks; exactly equals BSM at `F = S e^{(r-q)T}` |
| `monte_carlo.rs`   | GBM exact scheme; explicit `u64` seed; antithetic + BS control variate; `McResult{price, std_error, ci_low, ci_high}`; bit-reproducible per seed |
| `rng.rs`           | SplitMix64 -> xoshiro256++ -> Box-Muller, documented choice, platform-independent bit streams |
| `golden.rs`        | GENERATED cross-language golden vectors (`tools/gen_golden_rs.py`) |

Conventions (identical to the Python reference): continuously compounded
annualised `r`/`q` (ACT/365F), `T` in years, `sigma` annualised; theta per
**year**, vega per **unit** of vol, rho per **unit** of rate. Invalid
inputs (negative `S`, `K`, `T`, `sigma`; NaN or infinity anywhere,
including in the rates `r`/`q`) return
`Err(PricingError::InvalidInput)` — no panics on the pricing paths.
Negative `r` and `q` are fully supported.

## Build, test, benchmark

```sh
RUSTFLAGS="-D warnings" cargo test    # 85 tests (58 integration + 27 doctests), all green
cargo run --release --bin bench
```

Toolchain: Rust 2021 edition, cargo/rustc 1.95; `#![deny(missing_docs)]`;
no dependencies (see `Cargo.toml`).

## Cross-language golden validation (the headline)

`tools/gen_golden_rs.py` converts the Python project's committed
`tests/golden/golden_vectors.json` (32 cases: price + delta/gamma/vega/
theta/rho across ATM/ITM/OTM, short/long expiry, negative rates, dividend
yields) into `src/golden.rs`. The test suite requires every number to match
the Python reference to **1e-9**; the measured worst-case deviation is
**5.7e-14** — Python, C++ and Rust agree on all 32 x 6 numbers to within a
few ulps. See [docs/VALIDATION.md](docs/VALIDATION.md).

Also enforced: put-call parity to 1e-12 across a 486-point grid, Black-76
== BSM on the forward to 1e-12, CRR -> BSM convergence (2000 steps within
2e-3, error decaying with n), American >= European with `q=0` American call
== European, Monte Carlo within 3 standard errors with effective variance
reduction and bitwise seed reproducibility, analytic vs finite-difference
Greeks to 1e-6 (first order; 5e-6 second order), implied-vol round trips to
1e-8, and edge cases (`T=0`, `sigma=0`, `S=0`, `K=0`, extreme moneyness
`S/K` from 1e-4 to 1e4, 30- and 100-year expiries, negative `r`/`q`,
minimum path counts, invalid inputs returning `Err`).

**Validation contract on non-finite input.** Every public entry point
(`bs_price`, `bs_greeks`, `fd_greeks`, `d1_d2`, `crr_price`,
`early_exercise_premium`, `black76_price`, `black76_greeks`, `b76_d1_d2`,
`implied_vol`, `mc_price`) rejects NaN **and** +/-infinity in *every*
float argument — including the rates `r` and `q`, which a naive
`if x <= 0 { return Err(..) }` guard would wave through, because every
comparison against NaN is false. This is deliberately stricter than the
Python reference (which rejects NaN but lets `inf` propagate): a NaN
"price" trips no risk limit and colours no traffic light, so it is the
worst possible failure mode for a pricing library. `fd_greeks`
additionally refuses inputs where the down-leg of a central bump would
leave the domain (`sigma - h <= 0`, `s - h <= 0`, `t - h <= 0`), so a
caller-supplied pricer closure that does no validation of its own can
never be evaluated at a negative volatility or a negative spot.

## Benchmark (rustc 1.95, `--release`, 2 vCPU container, single run)

| Kernel | Work | Time | Throughput |
|---|---|---|---|
| Black-Scholes analytic | 1,000,000 prices | 83.5 ms | **12.0M prices/sec** |
| Full analytic Greek set | 100,000 evals | 7.7 ms | 13.0M evals/sec |
| CRR tree, n=1000, European | 1 tree | 0.58 ms | 1,739 trees/sec |
| CRR tree, n=1000, American | 1 tree | 5.51 ms | 182 trees/sec |
| Monte Carlo, 1M paths (antithetic+CV), 1 thread | 1 price + CI | 54.1 ms | 18.5M paths/sec |

Same order of magnitude as the C++ engine on the same machine (C++: 16.0M
BS prices/sec, 15.3M MC paths/sec single-threaded) — the two compile to
comparable machine code; differences are within run-to-run noise on a
shared container. Indicative single-run numbers; rerun
`cargo run --release --bin bench` locally.

## Layout

```
equity-options-engine/
├── Cargo.toml               # 2021 edition, zero dependencies, release LTO
├── src/lib.rs               # module tree + crate-level docs (deny(missing_docs))
├── src/*.rs                 # one module per model (rustdoc + doctests)
├── src/golden.rs            # GENERATED golden vectors — do not edit
├── src/bin/bench.rs         # std::time::Instant micro-benchmark (no criterion)
├── tools/gen_golden_rs.py   # JSON golden vectors -> src/golden.rs
├── tests/                   # integration suite (golden, identities, edges)
└── docs/                    # METHODOLOGY, VALIDATION, DESK_GUIDE
```
