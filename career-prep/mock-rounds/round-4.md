# Mock round 4: Quant developer (45 minutes)

Sit this cold, with a timer, on paper. Keys are in a separate file;
see [the debrief](README.md#debrief) once the time is up.

## Graded

- **M4.1** In how many ways can you climb 10 stairs taking one or two steps at a time?
- **M4.2** Worst-case number of probes for binary search on a sorted array of 1,000,000 distinct keys, when the key is absent?
- **M4.3** How many inversions (pairs i < j with a[i] > a[j]) does [3, 1, 4, 1, 5, 9, 2, 6] have?
- **M4.4** A dynamic array starts with capacity 1 and doubles when full. How many reallocations happen while appending 1,000 elements?

## Discussion

- **M4.5** Design a class that returns the median of the last N prices in a stream.
- **M4.6** A pricing service is slow. How do you find out why?
