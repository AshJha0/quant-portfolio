quant-portfolio

quant-portfolio is a set of study implementations of standard quantitative-finance models: option pricing, volatility forecasting, VaR and expected shortfall, fixed income, pairs trading, credit scoring, portfolio optimisation, execution scheduling, volatility surfaces and regime detection. Each area is written in Python with equity conventions and again with FX conventions. The option-pricing and VaR libraries also have C++ and Rust ports, tested against the Python code and, for options, against an mpmath oracle. All results on this site come from seeded synthetic data unless a page names a dataset. The code has not been used on a live book.

The 10 project areas

01

Options Pricing & Greeks

Black-Scholes / Garman-Kohlhagen closed form, analytic and finite-difference Greeks, CRR binomial trees for American exercise, implied vol by a safeguarded Halley iteration, Monte Carlo cross-checks. C++ and Rust ports.

02

Volatility Modelling

GARCH-family forecasting of realized volatility, clustering and mean reversion, forecast validation against a naive benchmark.

03

VaR / Expected Shortfall

Historical, age-weighted, parametric (Cornish-Fisher) and Monte Carlo VaR with full book revaluation; Kupiec and Christoffersen backtests and a Basel traffic light for any window. C++ and Rust linear-book ports.

04

Fixed Income

Bond pricing, yield-to-maturity solving, duration/convexity/DV01, yield curve construction, day-count conventions.

05

Statistical Pairs Trading

Cointegration testing, hedge-ratio estimation, z-score entry/exit, market-neutral spread construction and backtesting.

06

Credit Risk

Probability-of-default modelling, discrimination and calibration validation, expected-loss estimation.

07

Portfolio Optimisation

Mean-variance, minimum-variance and risk-parity allocation, constrained optimisation, marginal/component risk attribution.

08

Algorithmic Execution

TWAP/VWAP/participation-rate scheduling, market-impact modelling, implementation-shortfall and transaction-cost analysis.

09

Volatility Surfaces

Raw-SVI smile/skew surface construction with Durrleman no-arbitrage checks, Heston stochastic volatility (little-trap characteristic function) with Monte Carlo pricing; SABR is discussed as an alternative, not implemented.

10

Regime-Switching Strategies

Regime detection, regime-conditional signals, walk-forward validation against overfitting to hindsight-obvious regimes.

Foundations and engines

F1–F3

Foundations

Single-asset risk metrics on synthetic data, a moving-average backtest with fills modelled at t+1, and a Black-Scholes rebuild using only math.erfc, checked against a Monte Carlo pricer.

C++ / Rust

Compiled ports

C++23 and Rust ports of the options and VaR libraries. No runtime dependencies beyond the standard library; C++ tests use GoogleTest. The VaR ports revalue linear books only. They are ports of the Python design, not independent derivations. Shared code lives in cpp/core and rust/core, and the qp-cpp and qp-rust packages in bindings/ call the engines from Python.

Docs

Documentation contract

Each project states why it uses its model, what it assumes, how it was validated, where it fails and how it is meant to be used. Changes are listed in the changelog.

Quick start

Use a virtual environment outside the clone. Full commands are in CONTRIBUTING.md.

git clone https://github.com/AshJha0/quant-portfolio && cd quant-portfolio
python -m venv ../venv-qp && . ../venv-qp/bin/activate
cd python/equity/01-options-pricing
python -m pip install -c ../../../requirements/ci-constraints.txt -e ".[dev]"
python -m pytest -q
# a C++ engine, with the gcc preset (build tree under build/gcc)
cd cpp/equity-options-engine
cmake --preset gcc && cmake --build --preset gcc && ctest --preset gcc
# a Rust engine, from the Cargo workspace
cd rust && cargo test --release --locked -p eq-var-engine
